# The Daily Grind Café

A clean, responsive café website built with Next.js and Tailwind CSS.

## Features
- Multi-page site (Home, Menu) with client-side navigation
- Reusable Header and Footer components
- Responsive layout

## Tech Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Running locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000
